1. Inicializar un repositorio
Pregunta: ¿Qué comando se usa para iniciar un nuevo repositorio de Git en un proyecto local?
Respuesta: git init

2. Clonar un repositorio
Pregunta 2:
¿Cómo clonarías un repositorio remoto desde GitHub si tuvieras la siguiente URL? (Ejemplo: https://github.com/user/repo.git).
Respuesta: git clone https://github.com/user/repo.git

3. Hacer commit
Pregunta: Explica los pasos para hacer un commit de los cambios en un archivo index.js.
Respuesta: 
git add index.js --> Agrega el archivo al área de preparación
git commit -m "Mensaje descriptivo del cambio" --> Crea un commit con un mensaje

4. Ramas (branches)
Pregunta: ¿Qué comando se usa para inicializar un repositorio local con una rama llamada feature-login?
Respuesta: git init --> inicializa el repositorio
git checkout -b feature-login --> crea y cambia a la rama feature-login

5. Subir cambios a GitHub
Pregunta: ¿Qué comando envía los commits locales a la rama main del repositorio remoto?
Respuesta: git push origin main --> Este comando sube los cambios confirmados a la rama main del repositorio en GitHub
